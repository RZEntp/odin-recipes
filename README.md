# Introduction about the project 
-The project cover basic introduction to HTML5, Git, GitHub and other foundation which needs to be understand by the participant.
# Skills Acquired from this project
- Foundational knowledge on how to create index.html file, create page, sub-page, sub-folders, links, images, many other basics HTML6 skills which are essential for building foundation on web development. 
- Git and GitHub uses is covered, adding repos, cloning, adding, editing, committing and pushing files to Github via command lines.
# Project coverage and completion
- A small foundational web page - main index which link to other 3 recipes page was build and completed. 
- It consist of images, multiple headings, paragraph, unordered list, ordered list format, a "go back to home page" active link on each sub-page, images size were adjusted in order to accomodate text size neat and clean.
- A folder called "recipes" was created for site pages.
